# TFG — Previsión de demanda y planificación de la producción

Trabajo Fin de Grado del Grado en Ingeniería de Organización Industrial (URJC): *"Diseño de un sistema de previsión de demanda y planificación de la producción mediante flujos automatizados con IA"*.

- **Web de consulta (demo funcional):** https://rafa28229.github.io/tfg-prevision-demanda/
- **Documentación de la API de previsión:** [main_api.md](main_api.md)

La web consume por webhook un flujo de n8n que orquesta la previsión (API en Python), el cálculo del plan de producción y la redacción del informe de alertas.
